# Public-release checklist

- [ ] Confirm manuscript title and author list.
- [ ] Confirm repository name.
- [ ] Select institutionally approved software license.
- [ ] Remove all patient-level files.
- [ ] Search repository for patient IDs, dates, hospital numbers, names, and local Windows paths.
- [ ] Run scripts from a clean environment.
- [ ] Confirm all manuscript figure values against locked outputs.
- [ ] Add final figure-generation scripts.
- [ ] Create GitHub release corresponding to submitted manuscript version.
- [ ] Optionally archive the release in Zenodo and add the DOI to the manuscript.
