# Data availability

The individual-level longitudinal clinical data used in this study are not deposited in this public repository because they contain protected clinical information and are subject to institutional, ethics, and patient-privacy restrictions.

This repository therefore contains only:

- analysis code;
- environment specifications;
- aggregate, non-identifiable summary results;
- public analysis manifests without local file paths; and
- workflow documentation.

Researchers seeking access to the underlying data should follow the data-access process approved by the responsible institution and ethics/IRB framework. No patient-level data, dates, medical-record identifiers, or linkable clinical records should be committed to GitHub.
